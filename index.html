情報Ⅰ／数の表現 2進数の小数

小数を2進数にする2倍法

小数部分を2倍し、整数部を1桁として取り出す。整数部は消して、残った小数部分をまた2倍する。この繰り返しだけで10進小数は2進小数になります。下の「次へ」で1行ずつ進めて、どこが桁でどこが次の行へ送る数かを見分けてください。

0.
例

出力されるビット0 / 0 行

    気づき

    マスの下の数字は、その位の重み（1/2、1/4、1/8 …）。

    計算×2 → 整数部を取る → 小数部を残す

    回計算整数部＝ビット残る小数部

      整数部は2進数の1桁として取り出します。整数部を除いた小数部が、次の行で2倍する数になります。

      —

      0 / 0

      この単元の要点

      STEP 1

      小数部分を2倍する。0.625 → 1.25

      STEP 2

      整数部を1桁として書き出す。1.25 → 1（2進小数第1位）

      STEP 3

      小数部だけを残して繰り返す。0.25 を次の行へ。0 になったら終了。

      キーボード：→ / Space で次へ、← で戻る。
      既約分数にしたとき分母が2の累乗（2, 4, 8, 16 …）だけなら、2進小数は有限桁で終わります。分母に5が入る数（0.1、0.2、0.3 …）は終わりません。

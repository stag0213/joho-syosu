# 2倍法シミュレーター — 小数を2進数にする（情報Ⅰ）

10進数の小数を2進小数に変換する「**2倍法**」を、**1行ずつ**提示する授業用シミュレーターです。
HTMLファイル1つで動作し、インストールもネット接続も不要（フォント読み込みのみ外部参照）です。

- 対象：高等学校 情報Ⅰ「数の表現／2進数の小数」
- ファイル：`2倍法シミュレーター.html`
- 想定環境：Google Chrome / Microsoft Edge / Safari / Firefox の最新版（PC・タブレット・スマートフォン）

---

## 1. 使い方

1. `2倍法シミュレーター.html` をブラウザで開く（ダブルクリックでOK）
2. 変換したい小数を入力する（例：`625` ＝ 0.625）
   - 入力欄は「0.」が固定表示されているので、**小数点以下だけ**を入力します
   - 先頭に `0.` や `.` を付けても自動で取り除かれます。全角数字も受け付けます
3. **「次へ →」** を押すたびに、計算が1行ずつ確定します
4. 最後の行まで進むと、変換結果・検算・説明が黒いパネルに表示されます

### 操作

| ボタン | 動作 |
|---|---|
| **次へ →** | 1行進む（確定した行は青緑の帯でハイライト） |
| **← 戻る** | 1行戻る |
| **すべて表示** | 全行を一度に表示（結果まで確定） |
| **最初から** | 0行目に戻す |
| **自動再生** | 一定間隔で自動進行（もう一度押すと停止） |
| **速度**（ゆっくり／ふつう／はやい） | 自動再生の間隔。再生中に変更すると即反映 |

### キーボード操作

| キー | 動作 |
|---|---|
| `→` / `Space` / `PageDown` | 次へ |
| `←` / `PageUp` | 戻る |
| `Home` / `End` | 最初へ／最後へ |

※ 入力欄にカーソルがある間は、矢印キーは文字入力に使われます。`Enter` で確定＋1行進みます。

## 2. 画面の構成

| 領域 | 内容 |
|---|---|
| **入力** | 10進小数の入力、例のボタン（0.625／0.6875／0.75／0.1／0.2／0.3）、最大桁数の選択（8／12／16桁） |
| **出力されるビット** | 確定した2進小数をマス目で表示。各マスの下に位の重み（1/2、1/4、1/8 …）。循環節はオレンジ枠、繰り返し確認用の続きは点線マス |
| **気づき** | 点線マスが現れる瞬間に、「同じ4桁のくり返し」「何位から繰り返すか」を1文で提示 |
| **計算** | 1行＝1回の計算。`回 / 計算 / 整数部＝ビット / 残る小数部` の4列 |
| **結果** | 2進小数の式、1の位だけを足す検算、終了／循環／打ち切りの説明 |

### 色の意味

| 色 | 意味 |
|---|---|
| **青緑（緑のマス）** | 整数部として取り出したビット `1` |
| **白（枠のみ）** | ビット `0` |
| **オレンジの実線枠** | 循環節（繰り返す桁の範囲） |
| **点線のマス** | 循環の続き（同じ桁がもう一度並ぶことの確認用） |
| **オレンジの文字** | 次の行へ送る「残る小数部」 |

## 3. 収録している例

| 入力 | 2進小数 | 特徴 |
|---|---|---|
| 0.625 | `0.101` | 3桁で終了（分母 8） |
| 0.6875 | `0.1011` | 4桁で終了（分母 16） |
| 0.75 | `0.11` | 2桁で終了（分母 4） |
| 0.1 | `0.0`**`0011`**`0011…` | 4桁の循環。**小数第2位から**繰り返す |
| 0.2 | **`0011`**`0011…` | 4桁の循環。**小数第1位から**繰り返す |
| 0.3 | `0.0`**`1001`**`1001…` | 4桁の循環。**小数第2位から**繰り返す |

> **授業での使い方（例）**
> 0.625 で手順を確認 → 0.1 で「終わらない」ことに気づかせる → 0.1 と 0.3 を並べ、
> 「同じ4桁が繰り返すのに、繰り返し始める位置が違う」ことを確認 → 0.1+0.2 が 0.3 にならない話へ。

## 4. 表示される判定

| バッジ | 意味 |
|---|---|
| **有限小数・n桁で確定** | 小数部が 0 になった。2進数で正確に表せる |
| **循環小数・n桁の繰り返し** | 小数部が以前の値に戻った。以降同じ計算が繰り返される |
| **有限小数にならない・n桁で打ち切り** | 最大桁数に達しても 0 にならない。打ち切り時の真値との差も表示 |

「最大桁数」は循環の検出より優先されません。**循環が見つかった時点で自動的に止まり**、繰り返す桁を提示します。

## 5. 計算のしくみ（実装メモ）

内部では**すべて BigInt の分数**で計算しており、浮動小数点の誤差は一切入りません。

```
値は N / D（D = 10^小数桁数）として保持する
各ステップ：
  dbl = n × 2
  bit = (dbl >= D) ? 1 : 0
  rem = dbl − bit × D
  → bit がビット列の次の1桁、rem が次の行へ送る小数部
```

これにより `0.1 × 2 = 0.2` が `0.20000000000000001` のように表示されることはありません。
循環の検出は「**小数部の値が、それ以前の行と同じになったか**」で判定しています（値は既約とは限らないため、分子の値そのもので比較）。

### 制限

- 入力できるのは **0 より大きく 1 未満** の小数（小数第9位まで）
- 整数部は扱いません（整数部と小数部がある場合は、分けて変換して最後につなぐ指導を想定）
- 最大桁数は 8／12／16 桁

## 6. カスタマイズ

`2倍法シミュレーター.html` をテキストエディタで開き、以下を書き換えれば調整できます。

| 変更したいこと | 場所 |
|---|---|
| 例のボタンを増やす | `<div class="presets">` 内の `<button class="chip" data-v="625">` を複製（`data-v` は小数点以下のみ） |
| 最大桁数の選択肢 | `<select id="maxBits">` の `<option>` |
| 自動再生の速度 | `<select id="speed">` の `value`（ミリ秒） |
| 配色 | `<style>` 内の `:root` の `--green` / `--amber` / `--ink` など |
| 初期値 | `<input id="digits" value="625">` |

### 文字を大きくしたい（プロジェクター用）

`:root` の直後に次を追加すると、全体が1.25倍になります。

```css
html{font-size:20px}
```

## 7. アクセシビリティ

- ビット列・結果パネル・気づきの帯は `aria-live` で変化を読み上げ
- 全ボタンにキーボードフォーカスが当たり、フォーカスリングを表示
